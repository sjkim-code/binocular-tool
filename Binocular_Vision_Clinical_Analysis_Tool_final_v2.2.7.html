분석 결과

아직 분석되지 않았습니다.
입력 후 계산하기를 누르면 검사 완성도, 영역별 판정, 패턴 분석, 권고사항, 보고서 내용이 여기에 생성됩니다.

기존 기능 보존 요약

  • 계산하기 / 초기화 / 결과 출력 / 인쇄 유지
  • AC/A 계산, Sheard, Percival, Morgan 기준 비교 유지
  • NPC, 융합버전스, 조절력/조절용이성 입력 확장
  • CSV 내보내기 유지, JSON 저장/불러오기 추가
본 도구는 안경사의 양안시기능 검사 결과 정리와 임상적 판단을 보조하기 위한 참고용 소프트웨어입니다. 본 도구가 제공하는 결과는 의학적 진단을 의미하지 않으며, 단일 검사값이나 자동 분석 결과만으로 처방, 시기능훈련 또는 의료적 조치를 결정해서는 안 됩니다. 실제 판단은 굴절검사, 증상, 안위, 융합버전스, 조절기능, 감각기능, 검사 반복성 및 필요한 추가검사를 종합하여 사용자가 결정해야 합니다. 급성 복시, 현성사시, 안구운동 제한, 갑작스러운 수직편위, 신경학적 증상 또는 기타 병적 이상이 의심되는 경우에는 적절한 의료기관 평가를 고려해야 합니다.

도움말

증례 입력 → 검사값 입력 → 계산하기 → 비정상/경계 항목 우선 검토 → 패턴 분석과 추가검사/관리 검토사항 확인 → 인쇄 또는 저장 순서로 사용하십시오. 오프라인 단일 HTML이며 브라우저 내부에서만 계산합니다.
